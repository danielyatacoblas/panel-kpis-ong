# docs

Material de apoyo del repositorio.

- `video_kpi.mp4` — recorrido por el tablero: los indicadores, el selector de
  período, el filtro de canales y el asistente de análisis.

El reproductor del README principal apunta a una URL de attachment de GitHub;
el archivo de esta carpeta es la copia versionada. Enlazar directamente el
archivo del repositorio no sirve: GitHub lo sirve como
`application/octet-stream` y el navegador no lo reproduce.
